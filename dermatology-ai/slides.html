Concept Bottleneck Model (CBM)

HRNet backbone extracts visual features → ConceptBottleneck maps to 7 interpretable scores → classifier predicts benign / melanoma / Kaposi sarcoma. Each concept is measurable and clinician-inspectable.

Fairness-Weighted PPO

The RL agent's reward function applies 2–4× higher penalties for false negatives on darker skin (Fitz IV–VI). This actively counteracts the bias found in standard dermatology AI.

Human-in-the-Loop

Clinicians review AI triage and can override. Each correction is stored in a buffer, then used for offline PPO policy updates — the system continuously learns from expert feedback.

XAI & Auditability

Integrated Gradients + Grad-CAM heatmaps show what the model sees. Concept scores (asymmetry, border, color, etc.) give clinicians transparent, actionable reasoning behind each recommendation.
